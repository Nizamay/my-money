# Мои деньги — учёт расходов (iPhone, PWA)

Одно веб‑приложение (без сервера, без аккаунтов). Данные хранятся только в телефоне (localStorage).

## Что умеет
- Принимает SMS банков (через «Команды» iOS) или вставленный текст SMS, извлекает сумму, магазин, дату; доходы (зачисление, возврат) помечает отдельно и в расходы не считает.
- Источники: по отправителю/ключу (`BANK|*1234`) SMS относится к карте/банку; правила «слово → категория».
- Сегодня / неделя / месяц, графики по дням/неделям/месяцам, круговая диаграмма по источникам или категориям. Нажатие на столбик или сектор фильтрует список.
- Ручное добавление, смена категории прямо в списке (с предложением запомнить правило).
- Импорт истории из CSV/TSV или вставленных из Excel ячеек; выгрузка всего в CSV.

## 1. Разместить
iPhone должен открыть приложение по https. Проще всего — GitHub Pages:
залить эту папку в отдельный репозиторий → Settings → Pages → Deploy from branch.
Получится адрес вида `https://<логин>.github.io/my-money/`.

Откройте его в Safari → «Поделиться» → «На экран Домой».

## 2. Подключить SMS (iOS не даёт приложениям читать SMS напрямую)
Приложение «Команды» → «Автоматизация» → «+» → **Сообщение**:
1. «Отправитель» — выберите банк (или «Сообщение содержит» — например `Покупка`).
2. Включить **«Запускать сразу»**.
3. Действия:
   - «Текст»: `https://<ваш-адрес>/index.html#from=` + переменная **Отправитель** + `&sms=` + переменная **Содержимое сообщения**
     (лучше: действие «Закодировать URL» для содержимого и отправителя, затем подставить в текст).
   - «Открыть URL».

Приложение откроется, добавит трату и покажет уведомление. Одинаковое SMS дважды не засчитывается.
Для каждого банка — своя автоматизация (или одна с условием «содержит»).

Если что‑то не распознано — вкладка «Добавить» → «Вставить SMS».

## 3. Исторические расходы
Вкладка «Импорт»: файл .csv или вставка из таблицы. Колонки дата + сумма обязательны, источник/категория/комментарий — по желанию; колонки сопоставляются перед импортом.

## Важно
Данные живут только в Safari этого телефона. Периодически делайте «Скачать всё в CSV» — этот файл можно потом снова импортировать.
