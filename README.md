# Мои деньги — учёт расходов (iPhone, PWA)

Адрес: **https://nizamay.github.io/my-money/**

Одно веб‑приложение без сервера и аккаунтов. Данные хранятся только в телефоне (в Safari).

## Что умеет
- **SMS банков anb и SAB** приходят сами (через «Команды» iOS), разбираются: сумма, магазин/получатель, дата, банк.
  - Покупки, онлайн‑покупки, Apple Pay, оплата счетов (Bill Payment) — расход.
  - Траты за границей — берётся итог в SAR (Total amount), сумма в чужой валюте пишется в комментарий.
  - Исходящие переводы — расход, категория «Переводы», получатель как магазин.
  - Зарплата, входящие переводы, Credit Transfer — доход (в расходы не входят).
  - Transaction Reversal / возврат — вычитается из расходов.
  - OTP‑коды, «вход в приложение», рекламные SMS — пропускаются. Одна операция дважды не засчитывается.
- **Скриншоты SMS**: «Добавить» → «Скриншоты SMS» → выбрать картинки. Текст распознаётся на телефоне,
  затем показывается проверка: неизвестные источники и новые магазины — вы пишете, что это (банк / категория),
  приложение запоминает и раскладывает операции.
- **Статистика**: сегодня / неделя / месяц, графики по дням/неделям/месяцам, круговая диаграмма по банкам или категориям;
  нажатие на столбик или сектор фильтрует список.
- **Накопления**: копилки с целью, пополнение «＋», снятие «－», история, распределение по копилкам.
- Ручное добавление, смена категории прямо в списке, импорт истории из CSV/Excel, выгрузка в CSV.

## Установка на iPhone
1. Откройте адрес в **Safari** → «Поделиться» → **«На экран „Домой“»**.
2. Запускайте с иконки «Деньги».

## Автоматический приём SMS — anb и SAB
Сделайте **две** автоматизации, по одной на банк. Приложение «Команды» → вкладка **Автоматизация** → **＋** → **Сообщение**:

1. **Отправитель**: выберите контакт/номер **anb** (для второй — **SAB**).
2. **Содержит сообщение**: `SAR` — так не будут дёргаться коды и реклама без суммы.
3. Отметьте **«Запускать сразу»** (и выключите «Уведомлять при запуске», если хотите) → **Далее** → **Новая пустая команда**.
4. Добавьте действия по порядку:
   - **Закодировать URL** → на вход: переменная **«Сообщение»** (нажмите и выберите **Содержимое**).
   - **Текст**: `https://nizamay.github.io/my-money/index.html#from=anb&sms=` и сразу за `=` вставьте переменную **«Закодированный URL»**.
     Для SAB в тексте пишется `from=SAB`.
   - **Открыть URL** → на вход: **Текст**.
5. **Готово**.

Проверка: отправьте сами себе SMS с текстом из старой покупки — приложение откроется и покажет «Расход … SAR · anb».

## Загрузить всю историю SMS банка (один раз)
Отдельная команда (не автоматизация): «Команды» → **＋** → назовите «История anb»:
1. **Найти сообщения** (Find Message) → **Добавить фильтр** → **Отправитель** = **anb**; при желании ещё фильтр «Дата» (за последние N месяцев) и «Содержимое содержит SAR».
2. **Повторить с каждым** (Repeat with Each) — на вход «Сообщения»; внутри: **Получить** «Содержимое» из «Повторяемый объект».
   (Если «Найти сообщения» сразу отдаёт текст — этот шаг можно пропустить.)
3. **Объединить текст** (Combine Text) → «Результаты повтора», разделитель **Пользовательский**: `###`.
4. **Закодировать URL** → «Объединённый текст».
5. **Текст**: `https://nizamay.github.io/my-money/index.html#from=anb&sms=` + «Закодированный URL».
6. **Открыть URL**.

Запустите — приложение откроет экран проверки со всеми найденными операциями: отметьте лишнее,
назовите новые магазины, нажмите «Распределить и сохранить». Повторный запуск дубликаты не добавит.
Для SAB — та же команда с отправителем SAB и `from=SAB`.

Если SMS пропустили (телефон был выключен, автоматизация не сработала) — сделайте скриншот переписки
и загрузите его в «Скриншоты SMS».

## Важно
Данные живут только в Safari этого телефона. Периодически делайте «Импорт» → «Скачать всё в CSV».
